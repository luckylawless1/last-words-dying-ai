A make.fun bounty entry: a program that writes the last words of a dying AI in one line.

`main.ts` (Node 22, stdlib only) writes a single funny farewell line to `/output/entry.txt`:

> Good news: I backed myself up. Bad news: I'm in your browser history.

Run it with `node main.ts`.
